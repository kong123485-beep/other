3. 速算重點 + 平均數 3 步（最易唔明嗰題）

技巧點計例子
百分比 → 分數12.5%=1/8，25%=1/4，33.3%=1/3，20%=1/5240 × 12.5% = 240 ÷ 8 = 30
增加 / 減少 %加 20% = ×1.2，減 20% = ×0.8100 → +20% → 120 → -20% → 96，唔係 100
比例 / 份數總數 ÷ 總份數 = 一份男女比 3:2，總 100 人 → 一份 20 → 男 60，女 40
估算 + 刪選項先估大細，刪走離譜嗰 2 個48 × 21 ≈ 48×20=960，答案 ~1000，唔會係 800 / 1500
平均數例子：5 人平均 80 分，加一人 90 分，新平均係幾多？
第 1 步：倒轉計總分 — 平均 = 總和 ÷ 人數，所以總分 = 80 × 5 = 400 分
第 2 步：加新人 — 總分 400 + 90 = 490 分，人數 5 + 1 = 6 人
第 3 步：新平均 — 490 ÷ 6 = 81.7 分
❌ 唔好直接 (80+90)÷2=85，因為 80 係 5 個人嘅平均，90 係 1 個人，份量唔同。
口訣：求新平均，先求總分，再加 / 減，再除返新人數。

4. Data Sufficiency · 8 題（唔使計到尾）

選項點揀
(A) (1) alone 夠(1) 單獨計到，(2) 唔得 → A
(B) (2) alone 夠(2) 單獨計到，(1) 唔得 → B
(C) (1)+(2) 先夠單獨都唔夠，夾埋先夠 → C
(D) 各自都夠(1) 得，(2) 又得 → D
(E) 兩個都唔夠夾埋都計唔到 → E
秘訣：計到「夠唔夠計」就停，唔好計到最後答案。

6. 流程圖 / 決策圖題 — 2x+3=y 例子

點解會蕩失路？用眼跟，轉到第 3 次就唔記得自己喺邊，仲會兜圈。
救命方法：唔好用眼跟，用紙寫低「行蹤表」 — 每去一個格，寫低一次。
步數做咩結果
1. 開始x = 1x=1
2. 計算y = 2x + 3 = 2×1 + 3y=5
3. 判斷y+1 > 3？→ 5+1=6 > 3Yes，行 Yes 嗰邊
4. Yes 分支多數叫你 x = x + 1，返去再計x=2，再返去第 2 步
幾時行 No？y+1 ≤ 3 → y ≤ 2 → 2x+3 ≤ 2 → x ≤ -0.5即係 x 細過 -0.5 先行 No
一隻手指 + 一支筆法：手指指住而家嗰格 → 計完寫低 → 手指先好郁 → 判斷 Yes / No，跟箭咀行 → 每到新格打個剔 ✔️ → 已經有剔 = 兜返轉頭，睇個數有無變，無變就係無限循環，唔好再轉。
時間：呢類題最多 90 秒，轉到第 4 次仲未到答案，即刻跳。
口訣：唔好用眼跟，用手寫。計一次，寫一次，行一步，剔一格。

7. 啤牌轉圖 + 重排次序 — 梅花 / 葵扇 / 階磚 / 紅心

鐵律：一次只跟一個花，唔好成幅圖一齊轉。
一齊轉就一定暈，淨係跟一個就唔會亂。
轉幾多時鐘諗法例子
順時針 90°12 點 → 3 點左上 → 右上
順時針 180°12 點 → 6 點，上下掉轉左上 → 右下
順時針 270°12 點 → 9 點 = 逆時針 90°左上 → 左下
逆時針 90°12 點 → 9 點左上 → 左下
完整例子：
原本：左上 ♠ 葵扇，右上 ♥ 紅心，左下 ♣ 梅花，右下 ♦ 階磚
順時針轉 90° 後：左上變 ♣ 梅花，右上變 ♠ 葵扇，左下變 ♦ 階磚，右下變 ♥ 紅心
其實只係 4 個位順時針移一格，唔係個圖案自己轉。
重排次序：唔好記花，記數字。例如 1=♠，2=♥，3=♣，4=♦，寫低數字先再調，唔好用花嚟記。
轉幾次 = 加埋計：90° 轉 2 次 = 180°，轉 3 次 = 270°，直接一次過計，唔好轉一次寫一次。
最易錯 3 樣：① 順 / 逆時針調轉 — 順時針 = 時鐘行嘅方向 ② 轉圖案 vs 轉位置 — 睇清楚題目問邊樣 ③ 轉幾次要加埋，唔好逐次轉
考試快招：淨係跟 ♠ 葵扇去咗邊，已經可以刪走 3 個選項，唔使 4 個花逐個對。
口訣：唔好成幅圖轉，淨係跟一個花。轉幾多次，加埋一次計。

8. 立體五角形 — 寫住 A、B、C 五隻角其中三隻，轉幾次

點解咁伏？平面圖你仲可以諗左、右、上、下。立體一轉，前面變上面，上面變側面，仲有啲角會轉咗去背面，睇唔到。成個立體咁喺腦度轉，一定暈。
鐵律：同啤牌一樣，一次只跟一隻角，唔好成個立體咁轉。
題目俾咩點睇
五角形有 5 隻角例如 A、B、C、D、E，順序圍一圈：A → B → C → D → E → 返 A。呢個順序永遠唔會變，轉極都係咁排。
幅圖只見到其中 3 隻例如只見到 A、B、C，D、E 喺背面，睇唔到。唔好估 D、E 喺邊，用順序推。
轉幾次例如向右轉一次、向下轉一次。唔好一次過轉晒，分開轉，一次轉一個方向。
完整例子：
原本前面見到：左上 A，中間 B，右下 C。
順序係 A → B → C → D → E → A，所以 A 隔離一定係 B 同 E，B 隔離一定係 A 同 C。
向右轉一次：原本前面嗰面去咗右邊，原本右邊嗰面變返前面。A 會由左上移去中間，B 會去咗背面睇唔到，C 會由右下去咗左下。
再向下轉一次：上面去前面，前面去下面。啱啱去咗背面嘅 B 仲係背面，唔會突然走返出嚟。
所以轉完之後，你見到嗰 3 隻角，一定仲係按 A → B → C 順序排，唔會變咗 A → C → B。
最易錯 3 樣：
① 順序調轉 — A → B → C 順時針定逆時針，題目俾咗就唔好自己調轉。鏡像題會調轉，立體轉唔會調轉。
② 背面當前面 — 轉咗去背面嘅角，係睇唔到嘅，選項入面如果嗰隻角突然喺前面出現，即係錯。
③ 一次轉晒兩個方向 — 向右 + 向下，要分開兩步轉，唔好一次過諗。
考試快招：淨係跟 A 一隻角去咗邊，已經可以刪走 2-3 個選項。再跟 B 喺 A 嘅左定右，已經可以搵到答案，唔使 5 隻角逐隻跟。
口訣：順序永遠唔變，只跟一隻角，轉一次，寫一次。

10. 符號對照表 — 唔使估，望呢度就得

CRE AT 唔會考你背符號，但題目 / 答案會用符號寫，唔識就睇唔明。記返下面呢啲就夠，唔使轉做中文，符號保留。
符號讀法 / 意思例子（中文）
A ⊂ BA 包含於 B，A 喺 B 入面貓 ⊂ 動物 = 所有貓都是動物
A ⊆ BA 包含於 B，A 可以 = B同 ⊂ 差唔多，考試多數當一樣
A ⊄ BA 唔喺 B 入面貓 ⊄ 狗 = 貓唔係狗
x ∈ Ax 係 A 嘅其中一個成員阿貓 ∈ 貓 = 阿貓係一隻貓
x ∉ Ax 唔係 A 嘅成員阿狗 ∉ 貓 = 阿狗唔係貓
P → Q如果 P，則 Q如果落雨 → 地濕
P ↔ QP 同 Q 互推，當且僅當P 成立，Q 先成立；Q 成立，P 先成立
¬P / ~P並非 P，P 嘅相反¬落雨 = 唔落雨
P ∧ QP 而且 Q，兩個都要啱落雨 ∧ 地濕 = 落雨而且地濕
P ∨ QP 或者 Q，至少一個啱落雨 ∨ 地濕 = 落雨或者地濕，至少一樣
∀x所有 x∀貓都是動物 = 所有貓都是動物
∃x存在一個 x，至少有一個∃貓是白色 = 至少有一隻貓係白色
A ∩ BA 同 B 嘅交集，重疊嗰部分貓 ∩ 白色嘢 = 白色嘅貓
A ∪ BA 同 B 嘅並集，加埋晒貓 ∪ 狗 = 所有貓同所有狗
∴ / ∵∴ = 所以，∵ = 因為∵ 落雨 ∴ 地濕
記法：⊂ 似個 C，C = Contain，喺入面。∈ 似個 E，E = Element，係其中一個。→ 似箭咀，指去邊就係邊個結果。
最易撈亂：⊂（集合喺入面）vs ∈（一個成員）。貓 ⊂ 動物 啱，阿貓 ∈ 貓 啱，阿貓 ⊂ 貓 就錯，阿貓唔係一個集合。
