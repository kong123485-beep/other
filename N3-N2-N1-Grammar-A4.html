N3・N2・N1 文法重點 · 一張 A4

JLPT N3 + N2 + N1 · 考前重溫用 · 全部都係高頻必考句型

每條文法有 2 個例句，每句例句下面都有中文解釋（→ …）。每句例句下面都有中文翻譯。手機用法：按上方「遮住中文」可遮住中文意思＋中文解釋做自我測驗，點擊單張卡片可偷睇答案！N3打底 → N2拉闊 → N1文章語。

N3 · 中級打底（20 條）— 由 N4 跳去 N3 最關鍵

句型例句中文意思
〜てからでないと〜ない行ってからでないと分からない。
→ 要去咗之後先會知。
② やってみてからでないと、難しさは分からない。
→ 要試過之後，先會知有幾難。		要…了之後先會…
Vたところ、〜行ったところ、休みだった。
→ 去到先發現原來休息。
② 電話したところ、もう帰ったと言われた。
→ 打去先知佢已經返咗屋企。		去到先發現…
Vたばかり着いたばかりです。
→ 我啱啱到咗。
② 今、ご飯を食べたばかりだ。
→ 我啱啱食完飯。		剛剛…
Vようとする出ようとしたとき、電話が来た。
→ 正要出門嗰陣，電話嚟咗。
② 寝ようとしたとき、地震が起きた。
→ 正要瞓嗰陣，地震發生咗。		正要…
〜ことにする留学することにした。
→ 我決定去留學。
② 毎日30分勉強することにした。
→ 我決定每日溫書30分鐘。		決定…
〜ことになる来週行くことになった。
→ 變成下星期要去。
② 来月から大阪で働くことになった。
→ 變成下個月開始要喺大阪返工。		變成要… / 決定了…
〜ように言う早く来るように言われた。
→ 被叫要早啲嚟。
② 先生は毎日復習するように言った。
→ 老師叫我哋每日要複習。		被叫要…
Vてもらう / Vてくれる教えてもらった。
→ 我請人教我。
② 友達に写真を撮ってもらった。／友達が写真を撮ってくれた。
→ 我請朋友幫我影相。／朋友幫我影咗相。		請人幫我 / 人幫我
Vてほしい手伝ってほしい。
→ 希望你幫手。
② 静かにしてほしい。
→ 希望你安靜啲。		希望你…
〜ざるを得ない行かざるを得ない。
→ 不得不去。
② 証拠があるので、認めざるを得ない。
→ 不得不承認。
→ 因為有證據，不得不承認。		不得不…
〜ないわけにはいかない行かないわけにはいかない。
→ 不能唔去。
② 約束したので、行かないわけにはいかない。
→ 因為約咗，所以唔去唔得。
→ 不能唔去。		不能不…
〜にすぎない冗談にすぎない。
→ 只不過係講笑咋。
② これは私の意見にすぎない。
→ 呢個只不過係我嘅意見。		只不過是…
〜にほかならないこれは努力の結果にほかならない。
→ 呢個正係努力嘅結果。
② この成功はみんなの協力の結果にほかならない。
→ 呢個成功正係大家合作嘅結果。		正是…
〜にかかわらず年齢にかかわらず参加できる。
→ 不論年齡都可以參加。
② 天気にかかわらず、試合は行われる。
→ 不論天氣點，比賽都會舉行。		不論…
〜にしたがって年を取るにしたがって、忘れっぽくなる。
→ 隨著年紀大，變得健忘。
② 練習するにしたがって、上手になる。
→ 隨著練習，變得越來越叻。		隨著…
〜とともに結婚とともに、引っ越した。
→ 隨著結婚，搬咗屋。
② 人口が増えるとともに、店も増えた。
→ 隨著人口增加，舖頭都多咗。		隨著… / 同時…
〜によって人によって意見が違う。
→ 因人而異，意見唔同。
② 季節によって、景色が変わる。
→ 因季節唔同，風景都唔同。		因…而異 / 透過…
〜に対して彼に対して失礼だった。
→ 對佢好無禮。
② 子どもに対して、優しく話した。
→ 對小朋友溫柔咁講嘢。		對… / 相對於…
〜について日本について話す。
→ 講關於日本嘅事。
② 将来について考えている。
→ 諗緊關於將來嘅事。		關於…
〜ばかりでなく〜も安いばかりでなく、おいしい。
→ 不只平，仲好食。
② 彼は優しいばかりでなく、面白い。
→ 佢不只溫柔，仲好幽默。		不只…還…

N2 · 中高級（20 條）— 閱讀最常出

句型例句中文意思
〜ものだ子どものころはよく遊んだものだ。
→ 細個嗰陣成日玩。
② 学生のときはよく図書館で勉強したものだ。
→ 學生嗰陣成日喺圖書館溫書。		以前經常… / 本應…
〜ものかそんなことするものか。
→ 點會做啲咁嘅事呀！
② そんな嘘を信じるものか。
→ 點會信啲咁嘅大話呀！		點會…（反駁）
〜わけだだから来ないわけだ。
→ 難怪佢唔嚟。
② 毎日練習したから、上手になったわけだ。
→ 難怪咁叻，原來每日都有練習。		難怪…
〜わけがないそんなわけがない。
→ 點可能係咁呀。
② 彼が嘘をつくわけがない。
→ 佢點可能講大話呀。		點可能…
〜わけではない嫌いなわけではない。
→ 唔係話討厭。
② 疲れているわけではないが、少し休みたい。
→ 唔係話攰，只係想休息一陣。		唔係話…
〜どころか安いどころか、高い。
→ 別說平，反而貴。
② 暇どころか、毎日忙しい。
→ 別說得閒，反而每日都好忙。		別說…，反而…
〜どころではない遊ぶどころではない。
→ 而家唔係玩嘅時候。
② 今は泣いているどころではない。
→ 而家唔係喊嘅時候。		唔係玩嘅時候
〜としたら行くとしたら、明日だ。
→ 如果話去，就係聽日。
② 留学するとしたら、どの国がいい？
→ 如果話去留學，去邊個國家好？		如果話…
〜にしても行くにしても、準備が必要だ。
→ 就算去，都要準備。
② 買うにしても、よく比べてからにしたい。
→ 就算買，都想比較清楚先。		就算…也…
〜にせよ行くにせよ、行かないにせよ、連絡して。
→ 無論去定唔去，都要聯絡我。
② 賛成にせよ、反対にせよ、意見を言ってほしい。
→ 無論贊成定反對，都希望你講出意見。		無論…定…
〜をきっかけに留学をきっかけに、日本語を勉強した。
→ 以留學為契機，開始學日文。
② この本をきっかけに、歴史に興味を持った。
→ 以呢本書為契機，開始對歷史有興趣。		以…為契機
〜をめぐって環境をめぐって議論した。
→ 圍繞環境問題討論咗。
② 新しい法律をめぐって、議論が続いている。
→ 圍繞新法律，討論緊仲未停。		圍繞…
〜に際して卒業に際して、お礼を言う。
→ 喺畢業之際，講多謝。
② 入社に際して、抱負を述べた。
→ 喺入職之際，講咗抱負。		在…之際
〜に先立って会議に先立って、資料を配る。
→ 喺會議之前，先派資料。
② 発表に先立って、練習した。
→ 喺發表之前，練習咗。		在…之前
〜をもってこれをもって、閉会とする。
→ 以呢個為界，閉會。
② この賞をもって、努力が認められた。
→ 憑呢個獎，努力得到認同。		以… / 憑…
〜たところで行ったところで、間に合わない。
→ 就算去到，都趕唔切。
② 今から行ったところで、もう閉まっている。
→ 而家先去，都已經閂咗門。		即使…也…
〜からといって安いからといって、買うとは限らない。
→ 唔好因為平，就一定買。
② 若いからといって、できないわけではない。
→ 唔好因為後生，就話做唔到。		唔好因為…就…
〜といっても安いといっても、1万円だ。
→ 雖話平，都要一萬円。
② 一人暮らしといっても、実家は近い。
→ 雖話一個人住，但屋企好近。		雖說…，但…
〜というより安いというより、ただだ。
→ 與其話平，不如話免費。
② 暑いというより、蒸し暑い。
→ 與其話熱，不如話焗熱。		與其話…，不如話…
〜に違いない彼は来るに違いない。
→ 佢一定會嚟。
② 彼はこのニュースを知っているに違いない。
→ 佢一定知呢個消息。		一定…

N1 · 高級文章語（20 條）— 正式・書面・論文體

句型例句中文意思
〜を余儀なくされる中止を余儀なくされた。
→ 被迫要中止。
② 台風のため、延期を余儀なくされた。
→ 因為颱風，被迫要延期。		被迫…
〜ともなると社長ともなると、忙しい。
→ 一旦做到社長，就好忙。
② 親ともなると、責任が重い。
→ 一旦做咗父母，責任就好重。		一旦到了…
〜にあたって開店にあたって、挨拶する。
→ 喺開店之際，講番句說話。
② 新発売にあたって、社長が挨拶した。
→ 喺新產品推出之際，社長致辭。		在…之際
〜をもとに調査をもとに、報告する。
→ 以調查為基礎嚟報告。
② 実話をもとに、映画が作られた。
→ 以真人真事為基礎拍成電影。		以…為基礎
〜に則って法律に則って判断する。
→ 按照法律嚟判斷。
② 規則に則って、対応します。
→ 會按照規則嚟處理。		按照…
〜に沿って計画に沿って進める。
→ 沿住計劃嚟推進。
② 地図に沿って、歩いてください。
→ 請沿住地圖行。		沿著…
〜ながらも知りながらも、黙っていた。
→ 雖然知，但都冇出聲。
② 忙しくながらも、毎日日記を書いている。
→ 雖然忙，但每日都寫日記。		雖然…，但…
〜とはいえ安いとはいえ、質はいい。
→ 雖話平，但質素好。
② 初心者とはいえ、上手に弾くね。
→ 雖話係初學者，但彈得好好喎。		雖說如此…
〜ないでもない行きたくないでもない。
→ 也不是唔想去。
② もう一度行きたいくないでもない。
→ 也不是唔想再去一次。		也不是不想…
〜に足る読むに足る本だ。
→ 係一本值得睇嘅書。
② 信頼に足る人だ。
→ 係一個值得信任嘅人。		值得…
〜べく合格すべく、勉強する。
→ 為咗合格而溫書。
② 夢を叶えるべく、頑張っている。
→ 為咗實現夢想而努力緊。		為了…
〜がてら散歩がてら、買い物する。
→ 順便散步，順便買嘢。
② 買い物がてら、公園に寄った。
→ 順便買嘢，順便去埋公園。		順便…
〜を禁じ得ない涙を禁じ得ない。
→ 禁不住流淚。
② 彼の話に、感動を禁じ得なかった。
→ 聽到佢嘅說話，禁不住感動。		禁不住…
〜ならでは日本ならではの文化だ。
→ 只有日本先有嘅文化。
② 京都ならではの風景だ。
→ 只有京都先有嘅風景。		只有…才有的
〜に至って今に至って、後悔している。
→ 到咗而家，仲後悔緊。
② 今日に至って、やっと理解できた。
→ 到咗今日，終於明白咗。		到了…
〜をおいて彼をおいて、他にいない。
→ 除咗佢之外，冇其他人。
② 彼をおいて、この仕事は誰もできない。
→ 除咗佢之外，冇人做到呢份工。		除了…之外
〜にほかならないこれは努力にほかならない。
→ 呢個正係努力。
② この成功はみんなの協力の結果にほかならない。
→ 呢個成功正係大家合作嘅結果。		正是…（N1文章語）
〜ざるを得ない認めざるを得ない。
→ 不得不承認。
② 証拠があるので、認めざるを得ない。
→ 不得不承認。
→ 因為有證據，不得不承認。		不得不…（N1正式）
〜をよそに反対をよそに、進めた。
→ 不顧反對，繼續推進。
② 批判をよそに、彼は進み続けた。
→ 不顧批評，佢繼續前進。		不顧…
〜に先立ち開会に先立ち、挨拶する。
→ 喺開會之前，先致辭。
② 講演に先立ち、自己紹介をした。
→ 喺演講之前，先自我介紹。		在…之前（正式）
