1 · 歷史小說

《三國演義》· 羅貫中

元末明初 · 東漢末年 → 三國鼎立 → 西晉統一 · 七實三虛

核心主題

  • 忠義 vs 權謀：劉備講仁義，曹操講權謀
  • 分久必合，合久必分

必記人物

  • 劉備：仁德，桃園三結義
  • 諸葛亮：鞠躬盡瘁，草船借箭、借東風、空城計、三氣周瑜、七擒孟獲
  • 關羽：義絕，過五關斬六將、華容道義釋曹操
  • 張飛：喝斷長坂橋
  • 曹操：奸雄，寧我負人，毋人負我
  • 周瑜 / 孫權：江東基業，赤壁之戰

必記情節線

桃園結義 → 三英戰呂布 → 官渡之戰 → 三顧茅廬 → 赤壁之戰 → 三氣周瑜 → 大意失荊州 → 白帝城託孤 → 六出祁山

考試金句：滾滾長江東逝水，浪花淘盡英雄
2 · 英雄傳奇

《水滸傳》· 施耐庵

元末明初 · 北宋末年宋江起義 · 章回體

核心主題

  • 官逼民反：唔係天生反賊，係被逼上梁山
  • 忠義兩難：替天行道，又想招安

必記人物

  • 宋江：及時雨，主張招安
  • 林沖：八十萬禁軍教頭，風雪山神廟、火併王倫
  • 魯智深：拳打鎮關西、倒拔垂楊柳、大鬧野豬林
  • 武松：景陽岡打虎、醉打蔣門神、血濺鴛鴦樓
  • 李逵：黑旋風，忠勇魯莽
  • 吳用：智多星，智取生辰綱

必記情節線

智取生辰綱 → 三打祝家莊 → 大鬧大名府 → 108將排座次 → 招安 → 征方臘，悲劇收場

結構重點：前半聚義，後半招安征戰，英雄末路
3 · 神魔小說

《西遊記》· 吳承恩

明代 · 唐僧西天取經 · 融合佛、道、儒

核心主題

  • 取經 = 修心：九九八十一難，每一難都係一次心魔
  • 團隊合作：每個人代表一種人性

必記人物

  • 孫悟空：心猿，大鬧天宮、三打白骨精、真假美猴王
  • 唐僧：執著慈悲但不辨妖魔，緊箍咒
  • 豬八戒：慾望、懶惰、好色，高老莊
  • 沙僧：忠厚任勞任怨，流沙河
  • 白龍馬：默默付出

必記情節線

石猴出世 → 大鬧天宮 → 五指山壓五百年 → 收徒 → 三打白骨精 → 火焰山借芭蕉扇 → 女兒國 → 真假美猴王 → 取得真經

考試常考：三打白骨精象徵好心被誤解；五指山象徵心被束縛
4 · 古典巔峰

《紅樓夢》· 曹雪芹

清代 · 封建大家族由盛轉衰 · 又名《石頭記》

核心主題

  • 封建家族衰亡 + 愛情悲劇
  • 金陵十二釵：千紅一窟（哭），萬艷同杯（悲）

必記人物

  • 賈寶玉：叛逆貴公子，不愛仕途經濟
  • 林黛玉：敏感、才華、多愁，葬花吟、焚稿斷痴情
  • 薛寶釵：端莊識大體，冷香丸、金鎖
  • 王熙鳳：鳳辣子，機關算盡
  • 賈母：家族最高權威

必記情節線

木石前盟（寶黛） vs 金玉良緣（寶釵） → 劉姥姥三進榮國府 → 元春省親 → 抄檢大觀園 → 黛玉焚稿 → 寶玉出家，賈府抄家

考試金句：滿紙荒唐言，一把辛酸淚 / 假作真時真亦假，無為有處有還無
黛玉葬花：花謝花飛花滿天，紅消香斷有誰憐
